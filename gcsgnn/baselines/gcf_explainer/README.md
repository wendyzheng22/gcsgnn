# GCFExplainer

This folder contains the modified code for the paper "Global Counterfactual Explainer for Graph Neural Networks." The original repository can be found in the original_code folder or [here](https://github.com/mertkosan/GCFExplainer)

> Kosan, M., Huang, Z., Medya, S., Ranu, S., & Singh, A. (2024). GCFExplainer: Global Counterfactual Explainer for Graph Neural Networks. ACM Transactions on Intelligent Systems and Technology.
