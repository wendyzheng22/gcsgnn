# gnn-explainer

This folder contains the modified code for the paper "ProtGNN: Towards Self-Explaining Graph Neural Networks." The original repository can be found in the original_code folder or [here](https://github.com/zaixizhang/ProtGNN)

> Zhang, Z., Liu, Q., Wang, H., Lu, C., & Lee, C. (2022, June). Protgnn: Towards self-explaining graph neural networks. In Proceedings of the AAAI conference on artificial intelligence (Vol. 36, No. 8, pp. 9127-9135).
