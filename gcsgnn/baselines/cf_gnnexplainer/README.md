# CF-GNNExplainer

This folder contains the modified code for the paper "CF-GNNExplainer: Counterfactual Explanations for Graph Neural Networks." The original repository can be found in the original_code folder or [here](https://github.com/a-lucic/cf-gnnexplainer)

> Ana Lucic, Maartje ter Hoeve, Gabriele Tolomei, Maarten de Rijke, and Fabrizio Silvestri. CF-GNNExplainer: Counterfactual explanations for graph neural networks, 2022.
