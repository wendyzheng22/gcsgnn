# gnn-explainer

This folder contains the modified code for the paper "InduCE: Inductive counterfactual explanations for graph neural networks." The original repository can be found in the original_code folder or [here](https://github.com/idea-iitd/InduCE)

> Verma, S., Armgaan, B., Medya, S., & Ranu, S. (2024). InduCE: Inductive counterfactual explanations for graph neural networks. Transactions on Machine Learning Research.
