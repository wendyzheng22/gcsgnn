# gnn-explainer

This folder contains the modified code for the paper "GNNExplainer: Generating Explanations for Graph Neural Networks." The original repository can be found in the original_code folder or [here](https://github.com/RexYing/gnn-model-explainer)

> Rex Ying, Dylan Bourgeois, Jiaxuan You, Marinka Zitnik, and Jure Leskovec. Gnnexplainer: Generating explanations for graph neural networks, 2019.
